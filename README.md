# Stitch & Style website

A responsive static website for Stitch & Style car interior upholstery.

## Files
- `index.html` – website content
- `style.css` – layout and visual styling
- `script.js` – mobile navigation and WhatsApp enquiry form
- `assets/brand-slogan.jpg` – cropped slogan strip from the supplied artwork

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `stitch-and-style`.
2. Upload the contents of this folder (not the ZIP file) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. GitHub will provide the published website address after deployment.
